# Zero Graphics &bull; Official Website

> Premier Digital Printing, Flex &amp; Creative Artworks in Mecheda, Purba Medinipur, West Bengal (Est. 2000).

Modern multi-page website built with **Next.js (App Router)**, **Tailwind CSS**, and **TypeScript**.

---

## 🌟 Features & Disciplines

- **12 Core Printing Disciplines**:
  - Flex Print (High-Speed Konica 512i)
  - Eco-Solvent Print (Epson 1440 DPI)
  - Digital Print (Konica Minolta Digital Press)
  - Photo Print (Heritage Xerox DocuColor oily gloss)
  - PVC Card Print (CR80 Thermal Sublimation)
  - Ishanee Brand Envelopes (Proprietary colorful wedding & festive envelopes)
  - Digital Offset Print (Commercial bulk visiting cards & brochures)
  - Pre-Ink Stamp (Flash laser self-inking stamps)
  - B &amp; W, Colour Xerox (High-speed Xerox Docu250 copiers)
  - Jumbo Xerox (Wide-format CAD engineering drawings & blueprints)
  - Lamination Services (Thermal roll & pouch lamination)
  - Spiral Binding (Wire-O & plastic coil lay-flat binding)

- **Multi-Page Architecture**:
  - `Home (/)` &ndash; Hero showcase, 12 disciplines grid, Ishanee brand spotlight, workshop production lines.
  - `About Us (/about)` &ndash; Zero Graphics heritage since 2000, Bengali typography, machine milestones.
  - `Services (/services)` &ndash; Full technical substrate specifications, dimensions, instant WhatsApp ordering.
  - `Our Portfolio (/portfolio)` &ndash; High-resolution showcase of signages, corporate IDs, stamps, and envelopes.
  - `Contact Us (/contact)` &ndash; 2 physical branches (Thermal More &amp; Bus Stand), live Facebook page feed embed, customer care &amp; departmental WhatsApp desks.
  - `Ishanee Envelopes (/ishanee-envelopes)` &ndash; Dedicated catalog for Ishanee Brand celebratory covers.
  - `Machinery (/machinery)` &ndash; Technical profiles of Konica 512i, Epson Eco-Solvent, and Xerox presses.
  - `Price Calculator (/pricing)` &ndash; Interactive quotation calculator with WhatsApp export.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
